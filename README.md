# Douban to Netflix Searcher

这是一个轻量级的油猴脚本，旨在优化新加坡地区用户的豆瓣使用体验。

## 功能 (Features)
- 在豆瓣“想看”列表页自动添加 **Netflix** 搜索按钮。
- **智能提取：** 优先提取影片英文原名进行搜索，大幅提高新加坡区 Netflix 的匹配准确率。
- **自动清理：** 自动过滤标题中的年份信息。

## 安装 (Installation)
1. 确保浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击本项目中的 [douban_netflix_search.user.js](在此处填入你文件的真实链接) 即可自动触发安装。

## 适用场景
适合居住在新加坡、习惯使用豆瓣标记电影并拥有 Netflix 会员的用户。
